# MetaBinner species-level representatives and domain-specific phylogenies

Run scripts/main.nf with the four inputs archives (a file listing 42 MQ-or-better tarballs, one URI per line), metrics (the merged MAG_metrics CSV), worker (scripts/analyse.py) and image (the GTDB-Tk 2.8.0 BioContainer), plus a fresh result prefix.

The input audit matches the FASTA IDs exactly to the 5,390 passing CheckM2 records. Across all samples and strategies, skani computes pairwise ANI. In decreasing order of completeness minus five times contamination, each unassigned genome becomes a representative and recruits its still-unassigned direct neighbors with ANI ≥95% and alignment fractions ≥50% for both genomes. Ties use completeness, contamination, N50 and MAG ID. membership.tsv links every MAG to its representative and gives the observed similarity on both genomes (percent). This defines operational species clusters. The GTDB reference radius determines named species assignments separately.

GTDB-Tk 2.8.0 classifies representatives with reference release R232 and retains marker alignments even for ANI-classified genomes. The reference tarball is verified against the release MD5. FastTree with LG and gamma estimates separate unrooted trees from the masked bacterial bac120 and archaeal ar53 user alignments. Groups with fewer than two usable tips cannot yield a tree. The representative taxonomy table retains unassigned species and records tree inclusion. A missing species label denotes unresolved species-level classification. The two marker sets are never concatenated across domains.
